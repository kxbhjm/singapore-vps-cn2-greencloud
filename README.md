## 常见问题

**绿云新加坡 VPS 能解锁 Netflix 和 ChatGPT 吗？** 能。社区实测显示新加坡节点 IPv4 美区 TikTok、Disney+、Netflix、ChatGPT 全解锁，IP 归属干净。不过 Netflix 通常只解锁自制剧，这是新加坡节点的普遍情况，哪家都一样。

**10Gbps 端口是真能跑满吗？** 端口规格是真的，但属于公平共享：持续超过 100Mbps 跑 6 小时以上、或频繁打满端口，会触发限制。日常突发跑高速没问题，持续大流量传输不现实。

**买错了线路能退吗？** 分情况：新客户注册后 7 天内退首个 VPS 套餐可以；加密货币付款和活动促销机一律不退。这也是为什么建议第一次买选月付。

**新加坡普通线和 CN 优化线差多少？** 大陆方向差距很大：普通线实测电信绕欧洲 300ms+、移动绕纽约 400ms+，优化线走 CN2 GIA/CU 回程。东南亚本地访问两者都正常，按访问者所在地选就行。
